# CE108 First Tester Acceptance Checklist

## Purpose

最初の外部テスター1人に渡せる状態かを判定するための固定チェックリストです。対象は公開済みのFastAPIとmobileです。国家試験過去問の原文、LINE本番接続、写真・PDF OCR本番接続は対象外です。

## Environment

- [ ] FastAPI URL: `https://ce108-api.onrender.com`
- [ ] Mobile URL: `https://ce108-mobile.onrender.com/login`
- [ ] `/health`が200を返す
- [ ] mobileログイン画面がHTTPSで開く
- [ ] `NEXT_PUBLIC_ENABLE_DEMO_LOGIN=false`
- [ ] `CE108_CORS_ORIGINS`にmobile URLだけが設定されている
- [ ] SQLite DBがRender Diskの`/var/data/ce108.db`を使っている

## Tester Account

- [ ] テスター本人のメールアドレスで学生アカウントを作成した
- [ ] パスワードをチャット、README、GitHubへ保存していない
- [ ] 初回ログインに成功した
- [ ] 管理者画面またはAPIで`last_login_at`が更新されている

## Student Flow

- [ ] ホームに今日の学習状態が表示される
- [ ] 今日の5問を開始できる
- [ ] 回答前に正答、正答選択肢、選択肢解説が表示されない
- [ ] 1問回答すると正誤が表示される
- [ ] 解説、誤答選択肢の理由、復習日が表示される
- [ ] 図解がスマホ幅で読みやすく表示される
- [ ] 下部固定ボタンが解説本文や次の問題ボタンを隠さない
- [ ] 復習画面を開ける
- [ ] 理解度画面を開ける

## Note AI Flow

- [ ] ノートAI画面に注意文言が表示される
- [ ] 個人情報・患者情報を入れない説明をテスターへ伝えた
- [ ] テキスト貼り付けから問題生成できる
- [ ] `.txt`、`.md`、`.csv`のいずれかをアップロードして抽出できる
- [ ] 10MB超過ファイルで短く実用的なエラーが表示される
- [ ] 写真・PDFでは「読み取りは準備中」の短いエラーが表示される
- [ ] 生成問題に回答できる
- [ ] 生成問題の解説と図解を確認できる

## Feedback Flow

- [ ] フィードバック画面から意見を送信できる
- [ ] 管理者画面の「βフィードバック分析」で一覧を確認できる
- [ ] カテゴリ別件数が表示される
- [ ] 対応優先度が表示される
- [ ] 集中している論点の表と棒グラフが表示される
- [ ] 表示中のフィードバックをCSV出力できる

## Pass Criteria

- [ ] テスターがログインからフィードバック送信まで自力で完了した
- [ ] 学習を止めるエラーがない
- [ ] 正答情報が回答前に露出していない
- [ ] サンプル問題を公式過去問だと誤解していない
- [ ] ノートAIへ個人情報・患者情報を入力していない
- [ ] 管理者が活動状況とフィードバックを確認できる

## Stop Criteria

- [ ] ログインできない
- [ ] 今日の5問が表示されない
- [ ] 回答を保存できない
- [ ] 正答情報が回答前に見える
- [ ] 下部固定ボタンで主要操作が押せない
- [ ] フィードバックが保存されない
- [ ] 再起動でテスターのデータが消える

## Result

- 判定日:
- テスター:
- 判定: Pass / Conditional Pass / Stop
- 修正が必要な箇所:
- 次回確認日:
