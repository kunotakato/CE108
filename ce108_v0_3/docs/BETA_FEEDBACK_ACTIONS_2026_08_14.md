# Beta Feedback Actions - 2026-08-14

## 参照した実フィードバック

1. 問題・解説
   - 誤答がなぜ違うのか分かりにくい
   - 知識を太くする問題で何を学べるのか見せたい
   - みんなの正答率があると問題の重要さが分かりやすい

2. 使いやすさ
   - 難しい問題は、なぜその答えになるのかの流れが欲しい
   - 医学、特に解剖学は図があると理解しやすい
   - 言葉だけでは理解の定着が遅そう

## v0.4.4で対応したこと

- 回答後レスポンスへ`learning_point`を追加
- 回答後レスポンスへ`answer_statistics`を追加
- 学生モバイル回答後画面に「学習ポイント」と「β内正答率」を表示
- ノートAI生成問題の誤答解説を、本文との差分が分かる文面へ改善
- ノートAI回答後にも正答率と学習ポイントを表示
