# CE108 Mobile Alpha v0.3.5 UX Requirements

## 目的

学生がスマートフォンで毎日5問を5分から10分で完了できる学習体験を提供する。

## 対象

- 学生ロールのみ。
- 教員・管理者は既存の Streamlit 画面を利用する。
- 内部α版としてローカル起動とデモ学生ログインを前提にする。

## 必須画面

- ログイン
- オンボーディング
- ホーム
- 今日の問題
- 回答後解説
- 5問完了結果
- 理解度・苦手分野
- PWA manifest
- エラー・読み込み・空状態

## 操作要件

- iPhone 幅を優先し、320px でも横スクロールを出さない。
- 主要ボタンは44px以上のタップ領域を確保する。
- 回答ボタンは問題画面下部に固定する。
- Safe Area を考慮する。
- 回答前に正解、数値正解、選択肢解説、解説本文を露出しない。
- 二重送信を防ぐ。
- 通信失敗時は原因が分かる文言と再試行導線を表示する。

## API 連携

- `/api/auth/login`
- `/api/study/today`
- `/api/study/summary`
- `/api/study/mastery`
- `/api/questions/{id}`
- `/api/questions/{id}/answer`

## 範囲外

- LINE 本番認証・通知
- AIによる問題生成
- 公式過去問データ投入
- 教員・管理者のモバイルUI刷新
- データベース設計変更
