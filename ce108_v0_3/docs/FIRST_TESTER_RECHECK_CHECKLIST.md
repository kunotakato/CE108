# CE108 First Tester Recheck Checklist

## Purpose

履歴・復習から解説と図解を再表示できるか、最初の外部テスターに再確認してもらうためのチェックリストです。

## Environment

- [ ] API URL: `https://ce108-api.onrender.com`
- [ ] Mobile URL: `https://ce108-mobile.onrender.com/login`
- [ ] `/health` が200を返す
- [ ] テスター本人のアカウントでログインできる

## Daily Study

- [ ] 今日の5問を開始できる
- [ ] 回答前に正答・解説・選択肢解説が見えない
- [ ] 1問回答後に「解説と図解」へ移動する
- [ ] 正誤が分かる
- [ ] 標準解説が見える
- [ ] 誤答選択肢ごとの理由が見える
- [ ] 図解がスマホ幅で読める
- [ ] 「次の問題へ」で残りの問題へ進める

## Review Page

- [ ] 下部メニューの「復習」を開ける
- [ ] 復習予定が表示される
- [ ] 「解説と図解を見る」を押せる
- [ ] 回答済み問題の解説が表示される
- [ ] 図解が表示される
- [ ] 誤答選択肢の理由が表示される

## History Page

- [ ] ホームから「学習履歴を見る」を開ける
- [ ] 直近の回答履歴が表示される
- [ ] 正解/誤答ラベルが分かる
- [ ] 「解説と図解を見る」を押せる
- [ ] 解説・図解・誤答理由を確認できる

## Question Quality

- [ ] 問題が公式過去問だと誤解されない
- [ ] 国試対策らしいテーマに見える
- [ ] 説明が短すぎない
- [ ] 図解が理解の助けになる
- [ ] 不自然な選択肢があれば記録する

## Feedback

- [ ] フィードバックを送信できる
- [ ] 分かりにくかった画面名を本文に書ける
- [ ] 問題内容に違和感があれば問題文の一部を書ける

## Admin Confirmation

- [ ] ローカルStreamlitで `βフィードバック分析` を開ける
- [ ] テスター活動状況にログイン/回答/フィードバックが反映される
- [ ] カテゴリ別件数が見える
- [ ] 優先度別件数が見える
- [ ] CSV出力できる

## Result

- 判定日:
- テスター:
- 判定: Pass / Conditional Pass / Stop
- 修正が必要な箇所:
- 次回確認日:
