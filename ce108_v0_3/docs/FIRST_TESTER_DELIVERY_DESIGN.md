# CE108 First Tester Delivery Design

## Purpose

最初の1人にCE108を渡す目的は、機能の多さを見せることではなく、学生が「毎日5問なら続けられそう」と感じるかを確認することです。

この検証では、課金判断の前に次の3点を見ます。

- 初回ログインから今日の5問まで迷わず進めるか。
- 解説、復習日、苦手分析が学習に役立つと感じるか。
- 1,480円/月の価値がありそうかを本人の言葉で聞けるか。

## Target Tester

最初の1人は、次の条件に近い人を選びます。

- 臨床工学技士国家試験の受験予定がある。
- スマートフォンで学習する習慣がある、または作りたい。
- 率直に不満や迷った点を言ってくれる。
- CE108が未完成のβ版であることを理解してくれる。

避けるべき最初の相手:

- 公式過去問アプリと誤解しそうな人。
- 個人情報や学校資料をそのまま入力しそうな人。
- いきなり大人数に共有してしまう人。

## Product Promise For The Tester

最初のテスターに伝える価値は、次の一文に絞ります。

```text
CE108は、臨床工学技士国家試験に向けて、スマホで毎日5問を解き、解説と復習で苦手を減らすためのβ版学習アプリです。
```

現時点で約束しないこと:

- 合格予測。
- 公式過去問の網羅。
- AIが常に正しい解説を作ること。
- 学校や医療機関の非公開資料を安全に扱えること。

## Delivery Package

最初の1人に渡すものは、次の4点だけにします。

1. mobile公開URL。
2. 発行したテスター用メールアドレス。
3. 初期パスワード。
4. 10分で終わる確認手順。

渡さないもの:

- 管理者URL。
- 教員・管理者アカウント。
- RenderやGitHubのURL。
- 内部ドキュメント。

## Tester Message

そのまま送れる文面:

```text
CE108の最初の外部βテストをお願いしたいです。

目的は「スマホで毎日5問なら続けられそうか」を確認することです。
まだβ版なので、問題は操作確認用のオリジナルサンプルで、公式過去問ではありません。
参考換算点や学習提案は合格予測ではありません。

お願いしたいことは10分だけです。
1. URLを開く
2. 発行アカウントでログインする
3. 今日の5問を1問以上解く
4. 解説と復習日を見る
5. ノートAIに個人情報を含まない短い学習メモを入れて問題を作る
6. フィードバック画面から感想を送る

ノートAIには、個人情報、患者情報、学校の非公開資料、支払い情報は入れないでください。
迷ったところ、使いにくいところ、逆に続けられそうと思ったところをそのまま教えてください。

URL:
メール:
初期パスワード:
```

## First Session Flow

最初の1回は、この順番で使ってもらいます。

1. `/login`
   - 発行アカウントでログインできるか。
   - サンプル問題、合格予測ではないこと、個人情報禁止が読めるか。

2. `/onboarding`
   - 初期設定が難しくないか。
   - 毎日続ける時間を選べるか。

3. `/home`
   - 今日やることがすぐ分かるか。
   - 「今日の5問」または「復習から始める」が押したくなるか。

4. `/study`
   - 問題文と選択肢がスマホで読みやすいか。
   - 自信度を自然に選べるか。
   - 回答後の解説、誤答選択肢の解説、関連問題が役立つか。

5. `/reviews`
   - 復習日がある意味を理解できるか。

6. `/mastery` or `/strategy`
   - 苦手・得意やレーダーチャートが学習方針に使えそうか。

7. `/notes`
   - 注意文言を読んだうえで、非個人情報の学習メモだけを入力できるか。
   - 生成問題を「復習のきっかけ」として受け止められるか。

8. `/feedback`
   - 迷った点や価格感を送れるか。

## Questions To Ask After Use

テスターに聞く質問は5つに絞ります。

1. 最初のログインから今日の5問まで、迷った場所はありましたか。
2. 解説と誤答選択肢の説明は、復習に使えそうですか。
3. 毎日5問なら続けられそうですか。続かないとしたら理由は何ですか。
4. ノートAIは使いたいですか。不安な点はありますか。
5. 月1,480円なら使いたいと思いますか。高い/安い/妥当の理由も教えてください。

## Success Criteria

最初の1人で合格とする条件:

- 自力でログインできる。
- 今日の5問を1問以上解ける。
- 回答後の解説を読める。
- ノートAIの注意を理解できる。
- フィードバックを送信できる。
- 「毎日5問なら続けられそう」または「ここを直せば続けられそう」という反応が得られる。

## Fix Before Second Tester

次のどれかが起きた場合、2人目へ渡す前に修正します。

- ログインで詰まる。
- `Failed to fetch`が出る。
- 何をすればいいか分からないと言われる。
- サンプル問題を公式過去問だと誤解される。
- ノートAIへ個人情報を入れてよいと誤解される。
- 解説が信用できないと言われる。
- 1,480円の価値が伝わらない。

## Operator Checklist

渡す直前:

- `/health`が`0.4.3`を返す。
- mobile公開URLでログイン画面が開く。
- `CE108_CORS_ORIGINS`にmobile公開URLが入っている。
- `NEXT_PUBLIC_API_BASE_URL`がAPI公開URLを指している。
- `NEXT_PUBLIC_ENABLE_DEMO_LOGIN`が公開環境で`false`または未設定。
- テスター用学生アカウントを作成済み。
- 自分でそのアカウントのログイン確認済み。

渡した後:

- 24時間以内に感想を回収する。
- フィードバック内容を`beta_feedback`から確認する。
- 口頭・LINE等で追加ヒアリングする。
- 修正すべき点をv0.4.3候補として記録する。
