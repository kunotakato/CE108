## Automated QA

自動テストで確認している項目です。

- 30問診断が重複なく生成される
- 回答前APIで正答、数値正答、選択肢解説が露出しない
- 回答後に正誤、解説、選択肢別解説、図解が返る
- 数値問題の許容誤差が機能する
- 復習日が登録される
- seed問題の選択肢解説が空欄にならない
- 国試風オリジナル問題が140問以上のseed全体に含まれる

## Expert Review Boundary

このリポジトリ内で実施できるのは、形式、権利状態、回答前漏洩、表示、テストの確認までです。

医学的・工学的な最終監修は、あなた一人で完了扱いにしないでください。公開・課金前には、臨床工学技士、養成校教員、または各分野の専門家による確認が必要です。

## Human Review Checklist

- [ ] 問題文に医学的・工学的な誤りがない
- [ ] 正答が一意に決まる
- [ ] 誤答選択肢が不自然すぎない
- [ ] 誤答理由が正確で、学習者を誤誘導しない
- [ ] 数値問題の単位、桁、許容誤差が妥当
- [ ] 図解が本文・解説と矛盾しない
- [ ] 国家試験過去問の原文に近すぎない
- [ ] サンプル問題であり、公式問題ではないことが明記されている
