# CE108 Competitive Modeling

## Purpose

CE108を、臨床工学技士国家試験を目指す学生が毎日使う学習サービスとして強化するための競合モデリングです。

対象は、看護roo!国試アプリ、PT/OT/ST 国試 過去問 リハっ子アプリの公開ストア情報です。UI、文言、問題、解説、ブランド表現はコピーせず、学習体験の構造だけをCE108向けに再設計します。

## Reference Apps

### 看護roo!国試

公開情報から読み取れる強み:

- 約5000問、20年分という大きな問題量
- 全選択肢に解説がある品質訴求
- 単元別、年度別、正答率が高い問題、1日1問など複数の出題導線
- 苦手領域、絶対に落とせない問題をピンポイントで対策
- 模試、順位、現在地の確認
- 学習レポート、メーター、カレンダーによる継続可視化
- 頻繁な問題・解説修正と最新年度問題追加

CE108への示唆:

- 「問題数」だけで勝つのは難しいため、臨床工学技士向けの医学と工学の横断理解で差別化する
- 全選択肢の誤答理由、図解、関連問題を標準品質にする
- 毎日5問、復習、履歴、弱点分析を同じ導線でつなぐ
- 模試・過去問スコア入力から、次に解くべき分野を出す

### PT/OT/ST 国試 過去問 リハっ子

公開情報から読み取れる強み:

- 10年分以上の過去問
- 年度別、分野別、ランダム出題
- 1問ずつ解説、まとめて採点モード
- 学習履歴、弱点分析、正答率グラフ
- ブックマーク、間違えた問題だけの復習
- 中断再開
- 無料範囲と買い切りプレミアムの明確な分離
- 選択肢シャッフル、手書きメモ、問題画像拡大など細かい学習UX改善

CE108への示唆:

- 無料で価値を感じる入口と、有料で解放する価値を明確に分ける
- 「今日の5問」は無料体験として強い
- 有料化するなら、問題数そのものより、頻出分析、模試分析、個別復習、ノートAI、図解つき解説を中心にする
- 学習中断、再開、復習一覧、履歴再閲覧は有料以前の基本品質として維持する

## CE108 Product Positioning

CE108は、看護師やPT/OT/STではなく、臨床工学技士国家試験に特化します。

提供価値は次の順で設計します。

1. 毎日開けば、今日やることが分かる
2. 医学と工学の苦手分野が見える
3. 誤答理由と図解で、文字だけでは分からない内容を理解できる
4. 模試・過去問の点数から、時期に合わせて学習戦略を変えられる
5. ノートAIで、自分の授業メモや復習メモから問題化できる

## Features To Model

### Must Model Now

- 今日の5問
- 復習キュー
- 学習履歴からの解説再表示
- 誤答選択肢の理由
- 図解つき解説

- 模試・過去問スコア入力
- レーダーチャート

- 選択肢シャッフル

### Later

## Monetization Model

初期の価格仮説は月額1,480円です。

無料で提供する範囲:

- 今日の5問
- 一部の復習
- ノートAIの少量生成
- 基本の学習履歴
- フィードバック送信

有料で提供する範囲:

- 頻出テーマ別の全問題
- 医学重点、工学重点、バランス、直前得点最大化モード
- 模試・過去問スコア分析
- レーダーチャート詳細
- 間違えた問題だけ復習
- ブックマーク
- ノートAI生成数の拡張
- 図解・関連問題つきの詳細解説

買い切り案:

- 競合に買い切り2,200円の事例があるため、学生心理には買い切りも合う
- CE108は継続的な問題追加、AIノート、個別分析を含むため、月額の方が機能価値と運用コストに合う
- 初期は月額1,480円でテストし、外部テスターから価格感を必ず聞く

## Non-Copy Policy

次は禁止します。

- 競合アプリのUI、文言、画面構成の丸写し
- 過去問原文、外部解説、画像の無断転載
- 公式アプリまたは公式過去問と誤認される表示
- 監修前の問題を「国試品質保証済み」と表現すること

CE108では、国試頻出テーマをもとにしたオリジナル問題、独自解説、独自図解、独自の学習戦略導線として実装します。

## Highest Priority Roadmap

### P0: First Paid Tester Readiness

- 追加95問の専門監修ワークフローを回す
- 図解と解説が履歴・復習・今日の5問で確実に見える
- 管理者がフィードバックを一覧・集計で見られる
- スマホで下部ボタンが本文を隠さない
- テスター1人がログインからフィードバックまで完了できる

### P1: Daily Retention

- 今日の5問の達成感を強化
- 連続学習、週間履歴、未実施日のリカバリー
- 「次にやること」を常に1つ表示
- 間違えた問題だけ復習
- ブックマーク

### P2: Exam Score Improvement

- 頻出テーマ別演習
- 医学重点、工学重点、バランス、直前期モード
- 模試・過去問点数入力
- 分野別レーダーチャート
- 直前期は得意分野を伸ばし、通常期は苦手分野を潰す戦略切替

### P3: Paid Value

- 詳細解説、図解、関連問題
- ノートAI生成数拡張
- 監修済み問題セット
- 学習計画と進捗レポート
- 教員・学校向け集計

## Current CE108 Gap

すでに近いもの:

- 今日の5問
- 復習
- 履歴
- 解説と図解
- 誤答理由
- 苦手・得意分析
- 模試・過去問スコア入力
- レーダーチャート
- ノートAI
- フィードバック管理

まだ弱いもの:

- 問題品質の専門監修
- 問題数と頻出テーマの網羅性
- 図解の医学・工学別バリエーション
- 直前期向けの得点最大化導線
- ブックマークと間違えた問題だけ復習
- 有料/無料の境界
- 実テスターの継続利用データ

## Decision

次に新機能を広げるより、最初の外部テスターが毎日使って価値を感じる範囲を固めます。

優先順:

1. 追加95問の監修用CSVを使い、医学・工学の誤りを洗い出す
2. 誤答理由、図解、関連問題の品質を上げる
3. 復習と履歴から解説が確実に見えることを再検収する
4. フィードバック管理画面で不満の集中箇所を見える化する
5. ブックマーク、間違えた問題だけ復習、頻出テーマ別演習へ進む
