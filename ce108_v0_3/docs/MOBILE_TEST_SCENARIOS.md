# CE108 Mobile Alpha v0.3.5 Test Scenarios

## 自動テスト

- TypeScript 型検査: `npm run typecheck`
- ESLint: `npm run lint`
- API クライアント・コンポーネント: `npm test`
- 本番ビルド: `npm run build`
- E2E: `npm run test:e2e`

## E2E シナリオ

- デモ学生でログインできる。
- 初回オンボーディングを完了できる。
- ホームから今日の5問へ遷移できる。
- 5問に回答し、各問で回答後解説が表示される。
- 回答済みボタンが無効化され、二重送信を防ぐ。
- 5問完了後に結果画面へ遷移する。
- API エラー時にエラーUIを表示する。
- 320px、375px、390px、430px の横スクロールがない。

## 手動検収

1. FastAPI を `127.0.0.1:8000` で起動する。
2. Mobile Next.js を `127.0.0.1:3000` で起動する。
3. `student@ce108.local` / `demo1234` でログインする。
4. オンボーディングを完了する。
5. ホームの最初の画面内に「今日の5問を始める」が見えることを確認する。
6. 選択式、正誤式、数値入力の問題を回答する。
7. 回答前に正解・解説が見えないことを確認する。
8. 回答後に解説と復習日が表示されることを確認する。
9. 5問完了後、結果画面と理解度画面を確認する。
