# CE108 v0.4.4 Note OCR / Image AI Design

## 目的

学生が授業ノート、実習メモ、模試の復習メモから問題を作れるようにする。v0.4.4では外部βに渡す前の安全性を優先し、テキストファイル抽出を実装し、写真・PDF OCRは接続口と運用条件を固定する。

## v0.4.4で実装する範囲

- `POST /api/notes/extract`でノートファイルを受け取る
- `.txt`、`.md`、`.csv`をUTF-8として抽出する
- 最大ファイルサイズを`NOTE_OCR_MAX_BYTES`で制限する
- 写真・PDFが送られた場合、`NOTE_OCR_PROVIDER=disabled`では外部送信せず理由つきで停止する
- モバイルのノートAI画面からファイルをAPIへ送信する
- 抽出後、学生が本文を確認してから問題生成する

## v0.4.4で実装しない範囲

- 外部AI APIによる写真OCR
- PDF本文抽出
- 手書き文字認識
- 学校配布資料、患者情報、個人情報の保存・解析
- 生成問題の正確性保証

## 環境変数

```text
NOTE_OCR_PROVIDER=disabled
NOTE_OCR_MAX_BYTES=5242880
```

`NOTE_OCR_PROVIDER`は既定で`disabled`にする。外部OCRを有効化する前に、入力同意、保存期間、監査ログ、削除手順、禁止データをREADMEと画面文言へ反映する。

## 安全設計

- 外部βでは個人情報、患者情報、学校の非公開資料、支払い情報を入力しない
- 画像・PDFは既定では外部AIに送信しない
- 抽出した本文は学生が確認してから保存する
- 生成問題は公式過去問ではなく復習用オリジナル問題として表示する
- 生成内容は誤る可能性があるため、必ずノート本文と照合する

## 将来の接続候補

- OCR専用サービス
- OpenAI Vision/OCR相当API
- PDFテキスト抽出ライブラリ

どの方式でも、最初に「学生本人の同意」「入力禁止情報」「削除依頼時の運用」を確定する。
