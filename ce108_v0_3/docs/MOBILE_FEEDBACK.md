# CE108 Mobile Baseline Feedback

## 確認日

2026-07-01

## 対象

既存 v0.3 Streamlit 学生画面をスマートフォン幅 390px で確認した。

## 発見した課題

- ログイン画面は利用可能だが、デモアカウント案内が長く、スマホではフォーム以外の情報量が多い。
- 学生ホームは大きなヒーローと指標カードが先に表示され、「今日の学習」が初期表示より下に回る。
- 学習開始の主導線がファーストビューに出ないため、毎日5問を始める画面としては遠い。
- Streamlit のサイドバー操作がスマホでは主導線になりやすく、学生の日次利用には重い。
- 既存の教員・管理者画面は維持できる一方、学生の日次体験は専用モバイルUIに分離する方が安定する。

## v0.3.5 での対応

- 学生用 Next.js 画面を追加し、ホームの最初の画面に「今日の5問を始める」を配置した。
- 問題画面では回答ボタンを下部固定にした。
- 回答前の API レスポンスに正解・解説が混入した場合は表示を停止するガードを追加した。
- 320px から 430px までの横スクロール検査を E2E に追加した。
